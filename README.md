# Борд группы 15.27Д-С01/25б

Одна страница на группу: расписание всего семестра, калькулятор баллов по
балльно-рейтинговой системе РЭУ, контрольные точки и общая доска дедлайнов.
Открывается с телефона, ничего устанавливать не надо.

Личных данных на странице нет. Калькулятор считает прямо в браузере, введённые
пропуски и баллы никуда не уходят и никому не видны.

## Что здесь лежит

| Файл | Зачем |
|---|---|
| `index.html` | вся страница: вёрстка, логика, калькулятор |
| `data.js` | расписание и учебный план, генерируется скриптом — руками не править |
| `config.js` | адрес и ключ Supabase для доски дедлайнов |
| `build_schedule.py` | тянет расписание с rasp.rea.ru и пересобирает `data.js` |
| `supabase.sql` | создаёт таблицу доски и права доступа |
| `.github/workflows/update-schedule.yml` | раз в неделю обновляет расписание сам |

## Запуск: три шага

### 1. Репозиторий и сайт

Репозиторий — https://github.com/LockerBig007/rea-board, `origin` уже прописан.
Отправить из этой папки:

```bash
git push -u origin main
```

Дальше в репозитории: **Settings → Pages → Source: Deploy from a branch →
Branch: `main`, папка `/ (root)` → Save.** Через минуту-две сайт будет по адресу
**https://lockerbig007.github.io/rea-board/** — эту ссылку и кидайте одногруппникам.
В адресе Pages логин всегда строчными буквами, это нормально.

### 2. Доска дедлайнов

Без этого шага страница работает как справочник, только блок «Доска группы»
будет пустым.

1. Зарегистрироваться на [supabase.com](https://supabase.com), создать проект
   (бесплатный тариф, регион ближе к Европе).
2. **SQL Editor → New query**, вставить содержимое `supabase.sql`, нажать Run.
3. **Project Settings → API**: скопировать `Project URL` и ключ `anon public`.
4. Вписать оба значения в `config.js`, закоммитить и запушить.

Ключ `anon` публичный по замыслу — он и должен лежать в коде страницы. Секретный
`service_role` сюда класть нельзя.

Логинов у одногруппников нет, поэтому добавлять записи и отмечать сделанным
может любой, кто открыл ссылку. Кнопка удаления показывается только автору
записи. Если доску засорят — Table Editor в Supabase, удалить лишнее.

### 3. Автообновление расписания

Ничего делать не нужно: воркфлоу включается сам после пуша и по воскресеньям в
10:00 МСК перезабирает расписание. Проверить или запустить вручную —
вкладка **Actions → Обновить расписание → Run workflow**.

Если расписание понадобится обновить с компьютера:

```bash
python build_schedule.py
git add data.js && git commit -m "Расписание" && git push
```

## Новый семестр

В `build_schedule.py` поменять `PLAN` (учебный план из личного кабинета:
Рабочий учебный план → нужный семестр), `SEMESTER` (даты из графика учебного
процесса) и при необходимости `WEEKS`. Затем запустить скрипт.

Балл за одно посещение считается как 20 ÷ число пар, а число пар — это
контактные часы из учебного плана, делённые на два. Эта формула проверена на
фактических баллах из раздела «Рейтинг» личного кабинета и совпадает с
расписанием по каждому предмету.
