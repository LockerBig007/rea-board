Ответы к зачёту

Все 60 вопросов курса. У каждого — определение с нормой, структура ответа по пунктам, статьи и, где уместно, пример из проекта по авиапрому.

Каркас любого ответа — пять шагов, полторы минуты

  1. Определение и норма: «по статье такой-то закона № 273-ФЗ это…»
  2. Структура: сколько элементов и какие (перечень, классификация, уровни)
  3. Правовая основа: назвать акт и конкретный пункт
  4. Пример: своё дело из проекта — Тюрин или «МиГ»
  5. Вывод: какая мера снимает риск

Вопрос незнакомый — собирай ответ по формуле Клитгаарда: Коррупция = Монополия + Дискреция − Подотчётность. Почти любой ответ о причинах и мерах складывается из этих трёх переменных.
